# LucidDetox - Taste the Astral

Reality check reminder app for lucid dreaming practice.

## Features

- 🔔 5 meditation chime sounds
- ⏱️ Customizable intervals (5-120 minutes)
- 🎲 Randomize timing option
- 🔊 Volume control
- 📱 Progressive Web App (installable)
- 🌙 Perfect for lucid dreaming practice

## Installation

This app can be installed on any device:
- **Mobile**: Add to Home Screen
- **Desktop**: Install prompt will appear

## Usage

1. Choose your preferred chime sound
2. Set interval timing
3. Enable randomize for unpredictable reminders
4. Hit Start
5. Do reality checks when the chime sounds!
